How to Use This Tool

This tool allows you to simulate and compare different algorithms for optimizing 3D vehicle loading. Follow these steps to run an experiment:

  1. Open Simulation Settings:

    Click the Modify Simulation button at the top-right of the screen to open the configuration panel.

  2. Select an Algorithm:

    Choose one of the three available optimization algorithms: PSO, ACO, or the hybrid PSO-ACO.

  3. Choose a Vehicle:

    Select a vehicle capacity from the dropdown menu. The application will then automatically load a valid set of packages corresponding to that vehicle size, displaying the data on the left panel.

  4. (Optional) Set the Dynamic Constraint:

    Use the toggle switch to enable or disable the dynamic constraint. When enabled, the simulation will mimic a real-world disruption by removing 10-20% of packages from the final solution, forcing the algorithm to adapt.

  5. Run the Simulation:

    Click the Simulate button. A loading indicator will appear while the backend server performs the complex calculations. You cannot cancel the simulation while it is in progress.

  6. Analyze the Results:

    Once complete, the right-hand panel will display the outcome, including key metrics. If the simulation produced a valid result, a Visualize Result dropdown menu will appear, allowing you to view an interactive 3D model or watch loading and unloading animations.
